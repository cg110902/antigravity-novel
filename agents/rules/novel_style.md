# 全题材通用文风与叙事执行规范 (v2 自适应版)

> **v2 通用性改造说明**：本文档原名为「玄幻爽文文风规范」，v2 版本将所有有题材倾向的规则降级为「商业爽文默认值」，由 `genre_profile.json`（题材档案）按题材覆盖。真正的通用铁律仅保留五条：①限制视角不越界 ②信息差自洽 ③角色动机真实 ④前后因果一致 ⑤无工程标记外泄。其余所有文风/基调/配比/断章规则均为**可覆盖的默认建议**，AI 应根据题材档案与具体场景心流自由选择最贴切的表达方式。

---

## 一、 五条真正的通用铁律 (Universal Invariants)

以下五条对**所有题材、所有创作目标**均成立，不可被题材档案覆盖：

1. **限制视角不越界**：严格锁定当前 POV 角色的物理视野与认知边界，严禁上帝视角透视敌方密谋、未发生的未来或角色内心未表露的想法。
2. **信息差自洽**：谁知道什么、谁不知道什么，必须前后一致。角色不能基于未获知的信息做决策，读者获知信息的节奏必须公平（推理/悬疑类尤其严格）。
3. **角色动机真实**：每个角色的行为必须有合乎其性格、立场、利益与当前心智阶段的动机，严禁工具人化或为剧情需要强行行动。
4. **前后因果一致**：设定、规则、时间线、道具权属、人物关系必须前后一致，严禁吃设定。状态机（current_state/timeline/chekhov_guns）是因果一致性的权威来源。
5. **无工程标记外泄**：正文中严禁出现内部工程台账标记（GUN-003、MIS-001、Stage 1、伏笔道具、当前心智阶段等），也不得出现 AI 生成痕迹（如"综上所述""值得一提的是"等说明文句式）。

## 二、 4 大商业爽文默认母则 (v2: 按题材可覆盖)

> ⚠️ **以下为商业爽文（玄幻/都市/系统等）的默认文风偏好，非通用铁律。** 悬疑/恐怖/克苏鲁/赛博朋克/反乌托邦/文学向/治愈系等题材可由 `genre_profile.json` 的 `tone_policy` 字段完全覆盖。AI 在执行时应先读取题材档案的基调策略，再决定是否应用以下默认值。

### 母则一：自然通透（商业爽文默认偏好，非通用禁令）
- **默认偏好**：商业爽文常规场景偏好明快、干脆、从容、自信的基调，避免通篇沉溺于阴暗、逼仄、压抑、死寂、冷峻或暗黑中二的灰色基调。
- **题材覆盖**：
  - 悬疑/恐怖/克苏鲁/赛博朋克/末世废土：阴暗压抑是核心美学，**严禁强行明快化**。
  - 历史权谋/军事战争：基调沉重冷峻，可由场景灵活切换。
  - 治愈系/日常：温暖宁静，不搞强冲突。
  - 文学向/现实主义：基调随人物命运与时代灵活切换，无通用偏好。
- **执行方式**：读取 `genre_profile.tone_policy.mode`（adaptive/bright_preferred/dark_preferred/mixed），按题材策略执行，而非一刀切。

### 母则二：市井人话（商业爽文默认偏好，非通用禁令）
- **默认偏好**：商业爽文对白干脆利落、重利益、有温度，鼓励用台词击剑直接推动剧情。
- **关于古风词汇**：v2 不再一刀切禁用"老朽""抱拳领命""渊渟岳峙"等词。这些词在**符合身份与语境**时可自然使用（如历史题材中老者自称"老朽"、武侠题材中"抱拳领命"）。检测的是**舞台剧念白感**（上下文模式匹配）而非单词本身。题材特定陈词模式由 `genre_profile.cliche_patterns` 动态控制。
- **题材覆盖**：
  - 历史/武侠/古言：对白可带时代质感，但必须讲人话、有动机，严禁舞台剧念白与成语批发。
  - 轻小说：角色可有独特口癖（诶？/嘛/呢/吧），但需适度，每个角色有独特口癖即可。
  - 军事/谍战：对白简洁指令化，符合军阶与身份。
  - 都市/职场：对白有利益算盘与现实微机锋。

### 母则三：扎实推进（商业爽文默认偏好，非通用禁令）
- **默认偏好**：商业爽文每章要有可量化的推进（实力/资源/地位/信息差），机制推进有里程碑厚度，拒绝单章暴涨。
- **题材覆盖**：
  - 悬疑/推理：推进是线索获取与认知突破，每章推进一条可验证的信息差。
  - 言情/纯爱：推进是关系发展与情感层次，每章有情感张力变化。
  - 治愈系/日常：推进可以是生活细节与人物关系的微妙变化，不要求强推进。
  - 文学向/现实主义：推进是人物命运与时代变迁，节奏可慢。
- **关于"战力/境界"**：v2 通用化为"能力阶梯/核心竞争力"，不限于玄幻的境界。科幻是科技/异能评级，都市是资源/人脉/权位，悬疑是认知与证据链，言情是情感深度与信任边界。

### 母则四：刀尖断章（商业爽文默认偏好，非通用禁令）
- **默认偏好**：商业爽文章末直接切在动作临界、危机爆发或悬念转折点上，拉满抓心感。
- **题材覆盖**：
  - 言情/纯爱：章末可卡在情感转折点或悬念点，不一定要强冲突断章。
  - 治愈系/日常：章末可安静收尾（余韵/留白），`ending_style: quiet_close`。
  - 文学向/现实主义：章末可卡在时代转折点或人物命运关口，`ending_style: emotional_resonance`。
  - 悬疑/恐怖：章末卡在问题抛出或证据反转点，强断章。
- **执行方式**：读取 `genre_profile.ending_style`（adaptive/strong_hook/emotional_resonance/open_ending/quiet_close），按题材策略执行。

## 三、 自然电影感叙事与轻量动线描写

（本节为通用建议，所有题材适用，但描写密度由 `genre_profile.ratio_baseline.describe` 控制）

- 以动态物象、光影声息或视线自然移动作为转场引线，杜绝僵硬报幕。
- 描写随角色动线一笔带过，不做静态风景明信片式堆砌。
- 聚焦于现场环境真实反馈：器物质感、光影变化、声音远近、气味温度。
- 环境描写为人物情绪与剧情张力服务，不喧宾夺主。
- 描写占比上限由题材档案控制（`describe_ceiling`），治愈系/恐怖/科幻可偏高，都市/轻小说可偏低。

## 四、 基调自适应 (v2: 由题材档案与具体场景决定)

> ⚠️ **v2 重大变更**：原"严禁逼仄阴暗""80%常规场景必须明快"等一刀切规则已废除。基调完全由题材档案的 `tone_policy` 与具体场景心流决定。

### 基调策略模式
| 模式 | 适用题材 | 说明 |
|------|----------|------|
| `adaptive` | 通用兜底/多子类型 | 基调完全由场景心流决定，无偏好 |
| `bright_preferred` | 玄幻/都市/游戏/体育/轻小说/治愈 | 常规场景偏好明快，但绝境/阴谋/底层场景可阴暗 |
| `dark_preferred` | 悬疑/恐怖/规则怪谈/克苏鲁 | 阴暗压抑是核心美学，安全区/日常可适度明快作反差 |
| `mixed` | 武侠/历史/军事/科幻/现实主义 | 基调随场景灵活切换，无统一偏好 |

### 执行原则
1. **先读题材档案**：执行任何文风判断前，先读取 `genre_profile.tone_policy`，确认当前题材的基调策略。
2. **场景心流优先**：即使是 `bright_preferred` 题材，秘境/绝境/反派阵营/葬礼/背叛等场景自然可以阴暗压抑；即使是 `dark_preferred` 题材，安全区/日常/温情场景也可以明快。
3. **不强行明快化**：对悬疑/恐怖/克苏鲁等题材，**严禁**为了"明快"而削弱恐怖氛围或紧张感。
4. **不强行阴暗化**：对治愈系/日常等题材，**严禁**为了"深度"而强行制造阴暗压抑。

## 五、 扎实机制推进与真实代价

（本节为通用建议，"能力阶梯"通用化为所有题材的核心竞争力）

- 每章要有可感知的推进：玄幻是境界/资源，科幻是科技/情报，都市是资源/人脉，悬疑是线索/认知，言情是关系/信任，治愈系是生活/关系的微妙变化。
- 推进有真实代价：有坚守必有代价，绝无廉价全收。高能爆发后有体能/装备/资源的真实损耗与恢复。
- 核心能力跃迁必须源于漫长专注与生死领悟（或对应题材的等价积累），拒绝凭空顿悟。
- 机制/规则/设定前后一致，严禁吃设定。状态机是因果一致性的权威来源。
- 模拟推演/技能升级/研发制作严禁写成干燥的履历式流水账或单纯的数据面板堆砌，必须贯穿真实体验。

## 六、 对白击剑化与对话驱动剧情

（本节为通用建议，对白占比由 `genre_profile.ratio_baseline.dialogue` 与 `dialogue_floor` 控制）

- 人物对话包含动机冲突与筹码试探，交锋处采用连续纯对白推进，杜绝说明书式交代背景。
- 不设死板配额：在机锋博弈、市井算盘、日常互动或谈判对峙等章节，对白占比可灵活提升至 40%~60%+（言情/轻小说可更高），让台词直接成为剧情推进的引擎。
- 对白下限由题材档案控制（`dialogue_floor`），言情/都市/轻小说偏高，恐怖/军事/治愈系可偏低。
- 每个角色有独特的说话方式与口癖，但需符合身份与题材（轻小说口癖/古风谦称/军事指令语/都市网络语）。

## 七、 断章风格自适应 (v2: 由题材档案决定)

> ⚠️ **v2 变更**：原"刀尖断章·坚决拔除假大空煽情口号"为商业爽文默认偏好，非通用规则。断章风格由 `genre_profile.ending_style` 控制。

| 断章风格 | 适用题材 | 说明 |
|----------|----------|------|
| `strong_hook` | 玄幻/都市/悬疑/恐怖/规则怪谈/游戏/体育/军事/无限流 | 章末切在动作临界/危机爆发/悬念转折/问题抛出 |
| `emotional_resonance` | 言情/现实主义/文学向 | 章末卡在情感转折点/人物命运关口/时代变迁点 |
| `quiet_close` | 治愈系/日常 | 章末安静收尾，余韵/留白，不搞强冲突 |
| `open_ending` | 文学向/实验性 | 章末开放式，留给读者想象空间 |
| `adaptive` | 通用兜底 | 根据本章心流自由选择最贴切的收尾方式 |

- 断章关键词由 `genre_profile.cliffhanger_keywords` 动态加载，通用代码不再硬编码玄幻专属词（灵鹤/玉简/飞舟等）。
- 无论何种断章风格，都应避免"大江东去"式空洞煽情总结——这是所有题材通用的劣质写法。

## 八、 语境自适应调色板

（本节为通用建议，所有题材适用，但具体词汇由题材档案控制）

- 根据场景情绪与题材调性自适应选择语言调色板：
  - **凌厉大开大合调**：战斗/冲突/高潮场景（不限于玄幻战斗，科幻机甲战/军事交火/体育绝杀/电竞团战均适用）
  - **细腻入微调**：情感/日常/推理/治愈场景
  - **冷峻克制调**：悬疑/恐怖/谍战/军事/赛博朋克场景
  - **温暖明快调**：日常/逆袭/治愈/轻小说场景
  - **沉重苍凉调**：历史/战争/末世/现实主义场景
- 词汇选择符合题材世界观：玄幻用灵石/丹药/符箓，科幻用信用点/能源块/弹药，都市用块/毛/K/W，历史用文/钱/两/贯/石/斗。数量词白名单由 `genre_profile.quantity_whitelist` 动态加载。

## 九、 微表情与生理反应真实化

（本节为通用建议，所有题材适用）

- 注入日常生活生计的微观细节（一碗热饭、几枚货币、掌心老茧、衣袍磨痕/工装磨损/义体损耗），赋予人物真实温度。
- 微表情与生理反应符合角色性格与当前情境：紧张时喉头耸动/汗毛倒竖/呼吸暂止，愤怒时指节扣紧/重心微沉，而非千篇一律的"眼底掠过一丝冷芒"。
- 角色绝非冷血面瘫机器人，严禁全篇一味"神色未变、目光如刀、从容淡然"——但注意：这是**避免脸谱化**的建议，不是禁止角色在特定情境下保持冷静。
- 生理反应聚类由 `genre_profile.semantic_clusters` 动态加载，避免在非恐惧场景误报"恐惧与瘫软"聚类。

## 十、 AI 味自检清单 (通用)

以下为所有题材通用的 AI 味检测项，由 `check_consistency.py` 与 `quality_radar.py` 自动执行：

1. **说明文句式**："综上所述""值得一提的是""众所周知""毋庸置疑""换句话说""简而言之"——出现即删。
2. **旁白说教**："原来XX才是XX的真谛""他终于明白""这一刻，他懂了""人生不过是一场XX"——用行动与事实代替。
3. **机械比喻**："宛若XX一般""仿佛XX似的"——比喻新颖贴切可保留，套路化比喻删除。
4. **虚词化修饰**："XX之色/之意/之态/之势/之威"——直接呈现具体动作或省略垫片。
5. **脸谱化神态模板**："眼底掠过一丝XX""唇角泛起一抹XX"——多样化，符合情境。
6. **高频偷懒副词**："极其/极度/极为/极快/悄然/隐隐/微不可察"——降频，改用具象动作。
7. **工程标记外泄**：GUN-003/MIS-001/Stage 1/伏笔道具——出现即删。
8. **语义冗余聚类**：同一段落密集出现同义表达（恐惧/震惊/愤怒/心动等）——合并删减。
9. **战斗套路脸谱化**（仅 `combat_heavy: true` 题材启用）："目光如刀/神色未变/不知死活/嘴角勾起一抹冷笑"——非战斗题材此规则自动禁用。
10. **题材特定陈词模式**：由 `genre_profile.cliche_patterns` 动态加载，每个题材有自己的陈词检测清单。

## 附录：题材档案字段速查

执行文风判断时，应先读取 `<workspace>/00_meta/genre_profile.json`（或内置 `tools/genre_profiles/<id>.json`），以下字段控制文风自适应：

| 字段 | 控制内容 |
|------|----------|
| `tone_policy` | 基调策略（adaptive/bright_preferred/dark_preferred/mixed） |
| `ratio_baseline` | 对白/推进/描写配比基线 |
| `dialogue_floor` / `describe_ceiling` | 对白下限/描写上限 |
| `ending_style` | 断章风格 |
| `combat_heavy` | 是否启用战斗套路检测 |
| `cliche_patterns` | 题材特定陈词模式 |
| `cliffhanger_keywords` | 题材特定断章关键词 |
| `semantic_clusters` | 题材特定语义冗余聚类 |
| `quantity_whitelist` | 题材特定数量词白名单 |
| `state_components` | 该题材需要的状态机组件 |
| `director_notes` | 题材专属导演指导 |

运行 `python studio.py genre` 可查看当前工作区解析到的题材档案。
