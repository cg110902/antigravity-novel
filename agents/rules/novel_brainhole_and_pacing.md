# 全题材核心看点与爽点模型规范 (v2 自适应版)

> **v2 通用性改造**：原「玄幻脑洞与节奏规范」中的爽点模型已通用化为全题材适用。不同题材的核心爽点不同，但"读者心理欲望→情节兑现"的底层逻辑通用。

---

## 一、 核心看点提炼 (Universal Core Premise)

每本书必须有一个**一句话核心看点**（Logline），回答："读者为什么要追这本书？"

### 通用看点维度（不限于以下，鼓励自由创新）

| 维度 | 说明 | 典型题材 |
|------|------|----------|
| 认知破局 | 主角用独特理解/信息差/规则利用碾压对手 | 玄幻/都市/悬疑/规则怪谈 |
| 价值兑现 | 实打实获取资源/地位/情报/技术，杜绝虚无自嗨 | 全题材 |
| 利益交锋 | 高段位角色间的言语机锋、筹码拉扯、心理博弈 | 都市/历史/军事/言情 |
| 人物厚度 | 配角展现真实软肋、反差性格、独立动机 | 全题材 |
| 即时危机 | 倒计时/身份暴露/资源耗尽，拉满抓心感 | 悬疑/恐怖/军事/规则怪谈 |
| 双重视角 | 信息差导致的误判、马甲反差、降维打击 | 玄幻/都市/言情 |
| 硬核工匠 | 专业领域的技术美学、工艺细节、秩序美感 | 科幻/历史/游戏/体育/现实主义 |
| 规则破译 | 通过冷静试错与逻辑推演找到死穴机制 | 悬疑/规则怪谈/无限流/科幻 |
| 公道伸张 | 打破不公规则、击溃体制压迫、庇护同行者 | 全题材 |
| 岁月沧桑 | 在世事波折中参悟机理、心境洗礼与跃迁 | 历史/现实主义/玄幻 |
| 情感共鸣 | 关系发展、信任建立、情感张力与释放 | 言情/治愈系/全题材 |
| 日常治愈 | 生活细节、美食美景、萌宠互动、温暖人际 | 治愈系/轻小说/全题材调剂 |

### 执行原则
- 每本书选 2~3 个核心看点维度，形成差异化卖点。
- 核心看点在 `project_bible.md` 中明确记录。
- 每章至少兑现一个核心看点维度（不必每章都拉满，但不能连续 3 章全无看点）。
- 鼓励自由创新：以上维度仅为启发，完全可以提出全新的看点维度。

## 二、 读者心理欲望与爽点兑现 (Universal Reader Psychology)

### 通用爽点公式
```
期待（Setup）→ 延迟（Delay）→ 转折（Twist）→ 兑现（Payoff）→ 余韵（Aftertaste）
```

| 阶段 | 内容 | 通用化说明 |
|------|------|------------|
| 期待 | 建立目标/悬念/欲望，让读者想要什么 | 玄幻是夺宝/突破，悬疑是破案，言情是在一起，治愈系是做好一件事 |
| 延迟 | 引入阻力/意外/代价，让兑现不那么容易 | 不能让主角一帆风顺，延迟制造张力 |
| 转折 | 意外变量/信息差反转/规则突变，让情节多转一个弯 | 转折必须有铺垫，不能机械降神 |
| 兑现 | 目标达成/真相揭露/关系突破，释放积累的张力 | 兑现必须充分，不能虎头蛇尾 |
| 余韵 | 兑现后的影响/新悬念/情感沉淀，引导读者继续追 | 余韵是下一章的钩子 |

### 各题材爽点侧重
| 题材 | 核心爽点 | 兑现方式 |
|------|----------|----------|
| 玄幻/仙侠 | 升级/打脸/夺宝/装逼 | 境界突破、秒杀反派、获得法宝 |
| 武侠 | 武功/江湖/恩怨 | 武功大成、复仇、江湖地位 |
| 都市 | 逆袭/装逼/商战/身份反差 | 财富/地位提升、打脸看不起自己的人 |
| 科幻 | 技术碾压/探索/生存 | 科技突破、发现新文明、活下去 |
| 悬疑/推理 | 解谜/反转/真相 | 找到真凶、揭露诡计、认知颠覆 |
| 恐怖 | 恐惧/生存/未知 | 活下来、揭开真相、战胜恐惧 |
| 历史 | 权谋/种田/改命 | 改变历史、积累实力、位极人臣 |
| 规则怪谈 | 规则破译/生存 | 找到规则漏洞、活过副本 |
| 无限流 | 成长/通关/变强 | 通关副本、获得技能、变强 |
| 言情/纯爱 | 情感/关系/甜虐 | 在一起、误会解除、情感升华 |
| 游戏/电竞 | 技术/胜利/成长 | 夺冠、升级、技术突破 |
| 体育 | 竞技/突破/胜利 | 破纪录、夺冠、成长 |
| 军事 | 战斗/策略/成长 | 打胜仗、晋升、完成任务 |
| 轻小说 | 冒险/搞笑/成长 | 通关、获得伙伴、变强 |
| 现实主义 | 命运/时代/成长 | 改变命运、时代变迁、个人成长 |
| 治愈系 | 温暖/生活/成长 | 做好一件事、关系温暖、生活美好 |

## 三、 反路径依赖 (Anti-Path-Dependency)

### 通用套路陷阱（所有题材都要警惕）
1. **公式化冲突**：挑衅→秒杀、误会→解释、危机→外挂。每一次冲突都要有独特的解决方式。
2. **脸谱化反派**：反派无脑叫嚣、智商下线、为了作恶而作恶。反派必须有合乎利益的动机与智商在线的后手。
3. **工具人配角**：配角只在需要时出现、用完即弃。配角必须有独立动机与持续存在感。
4. **数值膨胀**：为了"显得厉害"不断加零、升级、换地图。能力阶梯锁控制膨胀节奏。
5. **重复场景**：连续多章在同一地点、同一类型冲突。场景与冲突类型要有变化。
6. **机械降神**：危机无法解决时突然出现新能力/新人物/新道具解围。转折必须有铺垫。

### 破局手段库（通用，不限于以下）
- 规则反噬：利用对手自己的规则/逻辑反制
- 信息暗战：通过信息差布局，让对手自己走进陷阱
- 利益招安：用利益捆绑/分化对手阵营
- 掀桌自救：打破现有规则/格局，创造新游戏
- 攻心诛心：心理战，瓦解对手意志/信任
- 因果借势：利用已有的伏笔/事件/人物关系
- 示弱诱敌：假装弱小，引对手深入后合围
- 技术降维：用专业知识/技术优势碾压
- 情感杠杆：利用人际羁绊/情感弱点
- 时间差：利用时间窗口/倒计时/先后顺序

## 四、 节奏密度与章节功能 (Universal Chapter Function)

### 章节类型（每章至少有一种主要功能）
| 类型 | 功能 | 节奏 |
|------|------|------|
| 推进章 | 主线目标取得实质性进展 | 紧 |
| 冲突章 | 正面冲突/对决/博弈 | 最紧 |
| 铺垫章 | 伏笔/人物/设定的铺垫与蓄力 | 松（但不水） |
| 转折章 | 意外变量/信息差反转/规则突变 | 紧 |
| 兑现章 | 目标达成/真相揭露/关系突破 | 紧→释放 |
| 调剂章 | 日常/幽默/人际/情感，调节节奏 | 最松 |

### 节奏搭配原则
- 连续 2 章紧（冲突/推进/转折）后，必须有 1 章松（铺垫/调剂）。
- 调剂章不是水章：必须在铺垫伏笔/深化关系/展示代价/丰富世界。
- 每 5~8 章必须有一个小高潮（兑现章）。
- 每卷（50~100 章）必须有一个大高潮。
- 治愈系/日常题材的"紧"可以是情感张力/生活事件，不必是战斗。

## 五、 黄金配比 (Universal Ratio Baseline)

> ⚠️ **v2 变更**：配比基线由 `genre_profile.ratio_baseline` 控制，不同题材不同。以下为通用兜底，具体以题材档案为准。

### 通用兜底配比
| 成分 | 占比范围 | 说明 |
|------|----------|------|
| 对白 | 20%~55% | 人物对话（含内心独白） |
| 推进 | 20%~55% | 动作/事件/剧情推进 |
| 描写 | 10%~40% | 环境/心理/细节描写 |

### 各题材配比侧重
| 题材 | 对白 | 推进 | 描写 | 说明 |
|------|------|------|------|------|
| 玄幻 | 25~45% | 35~60% | 10~30% | 推进为主 |
| 都市 | 35~60% | 20~45% | 8~25% | 对白驱动 |
| 科幻 | 25~50% | 30~55% | 12~35% | 均衡偏推进 |
| 悬疑 | 30~55% | 20~45% | 15~35% | 对白+描写 |
| 恐怖 | 15~40% | 15~40% | 25~50% | 描写为主（氛围） |
| 言情 | 40~65% | 10~30% | 15~35% | 对白为主（情感） |
| 治愈系 | 30~55% | 10~25% | 25~50% | 描写+对白 |
| 军事 | 20~45% | 35~60% | 12~32% | 推进为主 |
| 轻小说 | 35~60% | 20~45% | 12~30% | 对白驱动 |

- 配比由 `quality_radar.py` 自动检测，偏离基线出 WARNING（不阻断）。
- 配比是建议不是铁律：特殊场景（纯战斗章/纯对话章/纯描写章）可以偏离。

## 附录：脑洞自检清单

每章写完后，用以下清单自检：
1. 本章兑现了哪个核心看点维度？
2. 本章的爽点公式（期待→延迟→转折→兑现→余韵）是否完整？
3. 有没有落入公式化套路（挑衅→秒杀等）？
4. 反派/对手智商在线吗？有独立动机吗？
5. 本章在三线交织（主线/人际/暗线）中推进了哪条？
6. 章末钩子是什么？读者为什么想翻下一章？
7. 能力阶梯/经济数值有没有膨胀？
8. 有没有机械降神？转折有铺垫吗？
9. 配比是否在题材基线范围内？
10. 节奏搭配是否合理（前几章是紧还是松）？
