# 全题材角色一致性与防 OOC 规范 (v2 自适应版)

> **v2 通用性改造**：原「玄幻防 OOC 规范」中的角色一致性规则适用于全题材。"战力""境界"等玄幻特定表述已通用化为"能力""当前层级"。

---

## 一、 OOC 定义 (Definition of Out-of-Character)

OOC（Out of Character）= 角色行为偏离了已建立的性格、立场、动机、能力、心智阶段。

### OOC 的五种类型
| 类型 | 说明 | 示例 |
|------|------|------|
| 性格 OOC | 行为不符合已建立的性格特征 | 内向角色突然当众演讲、谨慎角色突然鲁莽冲动 |
| 立场 OOC | 行为不符合角色的立场/阵营/利益 | 正派角色无故作恶、反派角色无故行善 |
| 动机 OOC | 行为没有合乎角色的动机支撑 | 角色突然做了一件没有理由的事 |
| 能力 OOC | 角色使用了未建立的能力/知识 | 不会武功的角色突然使出绝世武功、不懂科技的角色突然修好飞船 |
| 心智 OOC | 行为不符合当前心智阶段 | Stage 0 被动求生的角色突然开始 Stage 3 规则重塑 |

---

## 二、 角色卡档案 (Universal Character Card)

每个重要角色必须有角色卡（`02_characters/profiles/<name>.md`），包含以下维度：

| 维度 | 内容 | 通用化说明 |
|------|------|------------|
| 基本信息 | 姓名/年龄/性别/外貌/身份 | 所有题材 |
| 性格特征 | 核心性格（3~5 个关键词）+ 行为模式 | 所有题材 |
| 底层动机 | 角色最想要什么、最害怕什么、底线是什么 | 所有题材 |
| 能力/技能 | 当前能力层级、擅长领域、弱点 | 玄幻是境界/武功，科幻是异能/科技，都市是资源/技能，悬疑是推理/观察力 |
| 人际关系 | 与其他角色的关系（盟友/对手/爱人/师徒） | 所有题材 |
| 心智阶段 | 当前 Stage（0~4）+ 触发事件 | 所有题材（详见 long_arc 文档） |
| 口癖/说话方式 | 独特的用词/语气/句式 | 由题材决定：轻小说口癖/古风谦称/军事指令语/都市网络语 |
| 成长弧线 | 角色的成长方向与关键节点 | 所有题材 |

### 规则
- 角色卡是角色行为的权威来源。写角色前先读角色卡。
- 角色卡随剧情更新：能力/心智/关系变化后，通过状态同步更新。
- 不重要的配角可以简化角色卡，但必须有基本动机与性格。

## 三、 心智阶段一致性 (Universal Mindset Stage Alignment)

角色行为必须符合 `character_growth_arcs.md` 中记录的当前心智阶段。

### 各阶段行为边界
| 阶段 | 可以做 | 不能做（OOC） |
|------|--------|----------------|
| Stage 0 被动求生 | 反应式应对、逃避、依赖他人、学习基本生存技能 | 主动布局、利用规则、引领变革 |
| Stage 1 主动求存 | 设定目标、试探规则、积累资源、主动学习 | 复杂布局、规则重塑、牺牲自我 |
| Stage 2 信息做庄 | 利用信息差、设计陷阱、反制对手、利益捆绑 | 打破根本规则、承担超越个人的使命 |
| Stage 3 规则重塑 | 打破旧规则、建立新秩序、引领变革、掀桌 | 回到被动/逃避、无视更大使命 |
| Stage 4 自我超越 | 牺牲、传承、升华、承担终极使命 | 自私逃避、拒绝成长 |

### 规则
- 心智跃迁必须有触发事件（inciting_event），记录在 `character_growth_arcs.md`。
- 不能跨阶段跳跃：Stage 0 不能直接跳到 Stage 2，必须经过 Stage 1。
- 不同角色可以在不同阶段，形成认知差与信息差（这是戏剧张力的来源）。
- 心智阶段模型适用于所有题材，但具体表现由题材决定。

---

## 四、 能力一致性 (Universal Power Consistency)

### 能力锁规则
1. **已建立的能力不能遗忘**：角色学会的技能/获得的装备/掌握的情报，后续不能突然消失（除非有合理的损耗/剥夺剧情）。
2. **未建立的能力不能突然出现**：角色不能突然使用从未展示过的能力/知识（除非有铺垫/学习过程/合理的觉醒）。
3. **能力有代价与限制**：每次使用能力有可感知的损耗（体力/资源/健康/副作用），不能无限使用。
4. **能力阶梯对齐**：角色的能力层级与 `current_state.md` 记录一致，不能突然暴涨。
5. **对手能力同步**：对手的能力与已建立的设定一致，不能突然变强/变弱。

### 各题材的"能力"对应
| 题材 | 能力类型 | 代价 |
|------|----------|------|
| 玄幻/仙侠 | 境界/武功/法术/法宝 | 灵气/体力/心魔/法宝损耗 |
| 武侠 | 内力/轻功/招式/兵器 | 内力损耗/经脉受损/兵器磨损 |
| 科幻/异能 | 异能/科技/装备/知识 | 能量/精神/义体损耗/副作用 |
| 都市 | 资源/人脉/技能/信息 | 资金/人情/健康/时间 |
| 悬疑 | 推理能力/观察力/情报 | 精力/心理/人身安全 |
| 言情 | 情感能力/社交/信任 | 情感创伤/信任破裂/时间 |
| 游戏/体育 | 技术/装备/状态 | 体力/伤病/心态/装备损耗 |
| 军事 | 战术/武器/体能/情报 | 弹药/伤亡/心理/资源 |

## 五、 人际关系一致性 (Universal Relationship Consistency)

### 关系锁规则
1. **关系变化有过程**：敌人变盟友、陌生人变爱人，必须有合理的互动过程与触发事件，不能一夜之间转变。
2. **关系有记忆**：角色之间的过往互动（恩怨/承诺/背叛）会影响当前行为，不能假装没发生过。
3. **误会台账管理**：信息差/误会记录在 `misunderstandings.md`，误会的发酵与解除有明确节点。
4. **角色独立动机**：每个角色有自己的目标与利益，不会为了主角的剧情需要而行动。

### 关系状态记录
- 重要关系状态记录在 `character_index.md` 或角色卡中。
- 关系变化通过状态同步（`state_inbox` 提案）更新。
- 误会/信息差通过 `misunderstandings.md` 管理。

## 六、 防 OOC 自检清单

每章写完后，用以下清单自检每个出场角色：

1. **性格**：角色的言行符合已建立的性格特征吗？
2. **立场**：角色的行为符合其立场/阵营/利益吗？
3. **动机**：角色为什么这么做？有合乎角色的动机支撑吗？
4. **能力**：角色使用的能力/知识是已建立的吗？有代价与限制吗？
5. **心智**：角色的行为符合当前心智阶段吗？
6. **关系**：角色与其他角色的互动符合已建立的关系吗？有记忆吗？
7. **口癖**：角色的说话方式符合角色卡中的设定吗？
8. **成长**：角色的行为是否体现了成长弧线？有没有倒退（除非有合理剧情）？

### 工具辅助
- `python studio.py pack ch_xxx` 会自动装载出场角色的完整人物卡与当前心智阶段。
- `python studio.py lint ch_xxx` 会检测角色名一致性与占位符。
- `track_character_decay.py` 检测角色掉线（超过 `stall_window` 章未出场）。

## 附录：OOC 常见陷阱与规避

| 陷阱 | 表现 | 规避 |
|------|------|------|
| 主角光环 | 主角突然获得未建立的能力/知识 | 能力必须有铺垫/学习过程/合理觉醒 |
| 反派降智 | 反派为了让主角赢而突然智商下线 | 反派必须有合乎利益的动机与后手 |
| 工具人 | 配角只在需要时出现、用完即弃 | 配角有独立动机与持续存在感 |
| 性格突变 | 角色性格一夜之间大变 | 性格变化必须有触发事件与过渡 |
| 关系跳跃 | 敌人一夜变盟友、陌生人一夜变爱人 | 关系变化有过程与触发事件 |
| 遗忘设定 | 角色学会的技能/获得的装备突然消失 | 能力有记录，损耗/剥夺有剧情 |
| 心智越级 | Stage 0 角色突然做 Stage 3 的事 | 心智阶段有记录，跃迁有触发事件 |
| 口癖混乱 | 角色说话方式前后不一致 | 角色卡记录口癖，写角色前先读卡 |
