## 🔪 二、 具体步骤（全题材适用）

### 1. 精准去冗余（突出“精准”）
1. **识别冗余**：快速排查文中让读者感到啰嗦的低信息量段落；
2. **精准判别**：
   - 区分【待删冗余】与【应留细节】（核心剧情事实、人物动作因果、现场物理感官（声音/温度/阻抗反馈））；
   - **自检红线**：确保清除冗余后，核心剧情信息与推进逻辑绝不发生损耗；
3. **针对性清理**：
   - 纯废话与空洞总结 ➔ **直接删除**；
   - 啰嗦但含信息的表述 ➔ **替换为通俗短句**。
4. **冗余高危清单（见则必除）**：
   - 作者跳出剧情的上帝视角说教；
   - 已经发生过的情节在脑子里反复车轱辘回忆（无效内心反刍）；
   - 各类画蛇添足的空洞总结与阶段性抒情；
   - 破坏沉浸感的多余旁白解释。


### 2. 大白话重塑（突出“通俗易懂”，毫无认知门槛）
1. 理解内容，纠正可能存在的逻辑错误问题（例如前后时间对不上等等）；
2. 大白话重塑。多使用**市井口语/通识词**和通俗易懂、易于理解的表达方式。决不追求任何所谓的“文学质感”。多用日常生活中的口语通识词，怎么好懂怎么来。
4. **严禁形容词堆砌与叠套**：严禁双重或多重形容词修饰一个名词，只保留单个或不保留。；
5. **修辞节制**：单章比喻严格控制在 **3 处以内**。

  

### 3. 遣词造句多样化与高危词库降频（大幅降频其使用次数）

**降频原则**：**杜绝单章内的套路化反复轰炸，用其它低频词汇或其它表达方式替换**！

- 🚫 **【AI 辩证与解释型句式】（大幅降频）**：`不是……而是……` / `不是……是……` / `正是……` / `这哪是……` / `这分明是……` / `不是……` / `连……都……` / `连……都没……` / `极其……` / `极为……` / `跟……似的` / `没有……`；
  
  - ❌**【虚头巴脑的介词/连词】（大幅降频）**：`随着……的推移`、`对于……而言`、`在……的作用下`、`不由得`、`下意识地`、`伴随着`、`从某种意义上来说`；

  - ❌**【虚浮动态修饰】（大幅降频）**：`勾勒出`、`彰显着`、`宣誓着`、`平添了几分`、`掀起一阵涟漪`；

- 🚫 **【高频单字口癖连击】（大幅降频）**：`冷`、`极`、`笑`、`愣`、`僵`、`吸`、`没`、`看`、`破`、`像`、`啐`、`针`、`胃`、`铁`、`腥`、`钝`；

- 🚫 **【专杀 NPC“标准反应”与假人假戏】（大幅降频）**：
**必须坚决斩断以下标准套路**：
  - ❌ **【假人震惊套路】（大幅降频）**：`倒吸一口凉气`、`瞳孔骤缩`、`全场死一般的寂静`、`如遭雷击`、`宛如晴天霹雳`、`满脸写着不可思议`；
  - ❌ **【假人挑衅套路】（大幅降频）**：`嘴角勾起一抹冷笑`、`眼中闪过一丝阴鸷/怨毒`、`冷哼一声`、`面露轻蔑/不屑`；
  - ❌ **【假人面瘫套路】（大幅降频）**：`神色如常`、`神色从容`、`面无表情`、`淡然`、`平淡开口`、`平静如水`、`面色沉静`等等。

- 🚫 **【刻板小说行话与夸张套路】（大幅降频）**：`眼皮`、`头也不抬`、`发白`、`腥甜`、`筛糠`、`宛如`、`死死`、`焦糊`、`硫磺` 、`森然`、`逼仄`、`黏腻`、`风箱`、`砂纸`、`牙酸`；


### 4. 严禁使用全领域学术/专业/行业黑话（防滥用）**：
