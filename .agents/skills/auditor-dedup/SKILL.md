## 🎯 一、 审查维度与执行规范

### 1. 商业情绪压水节拍与走过场清剿（该快就快，该慢就慢 · 严查秒过病）
- **严查戏眼走过场与概括报幕（秒过病）**：扫描核心高潮、关键攻防、生死急救或重要破局是否被 1~2 个自然段一笔带过（如“一番推拿逼出寒毒”、“拔剑数招逼退强敌”）；发现概括性糊弄直接标红；
- **戏眼工笔审查**：核心对抗必须写足具体的受力部位、冷汗阻抗、来回拉扯动作与环境即时反馈；
- **蓄水 ➔ 压制 ➔ 决堤**：检查核心对抗是否具备充分铺垫，严防平铺直叙；
- **秒射打脸清剿**：若对手施压不足、缺乏压制即被秒杀打脸，标明需在第 2 阶梯增加施压与受挫细节。

### 2. 对白潜台词（Subtext）
- **宣读动机诊断**：台词若过于直白宣读动机，标明改写为表面客套、底下杀机或利益试探的潜台词对撞。

### 3. 真实动作阻抗与受挫
- **阻抗反馈**：打斗动作必须有来有往，具有受阻与即时代价，禁止悬空大招。

### 4. 社会性群像微反应
- **配角活人反应**：检查配角、爪牙打手与围观群众是否有观察风向、利益算盘的小动作，禁止人肉背景板。

### 5. 剧情与情绪转折审查（可以转折，严禁突兀 · 平滑过渡铁律）
- **可以转折，但严禁突兀**：允许剧情反转、态度转变与场景切换，但**绝不允许缺乏因果铺垫的生硬断层**；
- **情绪断层审查**：严查角色情绪从暴怒到冷静、从绝望到窃喜是否缺乏缓冲或动作过渡；
- **立场突变审查**：严查对手或配角在没有利益受迫、实力震慑或心理阶梯的情况下突然反差倒戈；
- **场景硬切审查**：严查两幕之间、两个场景之间是否缺乏视线转移、动作离场或环境承接；
- **处置规程**：发现转折突兀处，必须定位段落，指出前因后果断层点，并**给出具体的动作、视线转移、缓冲或台词递进等平滑过渡建议**。

### 6. 绝杀断章强化
- **章末拖沓清理**：检查章末是否有多余感悟、环境抒情或心理总结；
- **断章定格建议**：指出具体定格瞬间（动作悬空、危机骤降、反转亮牌），建议落刀位置。

## 📝 二、 报告书写格式（`log/audit/ch_XXX_dedup.md`）

```markdown
# 第 ch_XXX 章 商业节奏与对白张力审校报告

## 一、 商业情绪压水与张力缺陷靶点（供终审主编重塑）
- [戏眼走过场靶点]：
  - 位置定位：第 [U] 段落 / 原文关联句：`“相关概括性原句片段”`
  - 病灶说明：核心戏眼被大段概括性叙事糊弄带过，缺乏受力部位、阻抗与来回攻防拉扯。
  - 改写建议：拉近镜头电影级慢放，展开具体的接触点、冷汗、阻抗反馈与来回拉扯动作。
- [情绪压水靶点]：
  - 位置定位：第 [X] 段落
  - 病灶说明：核心戏眼存在秒射现象，对手施压不足，缺乏窒息压制感。
  - 改写建议：增设反派步步紧逼或主角暂时受挫的台阶，蓄足势头再引爆。
- [对白潜台词靶点]：
  - 位置定位：第 [Y] 段落
  - 病灶说明：台词过于直白宣读动机（如“……”），缺乏城府与。
  - 改写建议：改写为表面客套、内藏杀机或利益试探的潜台词对撞。
- [阻抗靶点]：
  - 位置定位：第 [Z] 段落
  - 病灶说明：打斗缺乏反馈，动作悬空。
  - 改写建议：细化打斗过程。打斗动作必须实打实写出你来我往的受击反馈（根据题材不同而不同）
- [群像微反应靶点]：
  - 位置定位：第 [W] 段落
  - 病灶说明：配角与打手沦为人肉背景板，缺乏活人反应。
  - 改写建议：补充打手察言观色后退半步或周围人利益算盘的小动作。
- [平滑过渡靶点]：
  - 位置定位：第 [V] 段落
  - 病灶说明：转折突兀，从 [前一状态/场景] 跳跃至 [后一状态/场景] 缺乏因果铺垫与心理/动作缓冲。
  - 改写建议：补充 [具体动作/视线转移/反应/台词递进] 作为平滑过渡，让情节承接顺畅自然。

## 二、 绝杀断章定格建议（章末刀口）
- 当前章末现状：[说明当前稿件末尾是否存在抒情尾巴或多余感悟]
- 推荐定格瞬间：建议正文截断于第 [Z] 句（`“定格动作或对话原句”`），将悬念死死定格在最高潮。
```
