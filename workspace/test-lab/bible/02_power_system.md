## 二、 表现力与影响力具体标尺（Power & Impact Scale Anchors）

### 1. Tier 1（初始层）：淬体境
- **能力表现 / 业务表现物理标尺**：拳力三百斤，可持续两个时辰矿道重体力劳作；剑丸初醒者可越级感知十丈内杀机。
- **社会 / 财富影响力标尺**：手握数块至数十块下品灵石，在杂役圈子中略有说话分量。
- **能力 / 感知极限**：神识仅能离体三尺，无法长时间御物，连续作战超过一刻钟必力竭。

### 2. Tier 2（中坚层）：聚气境
- **能力表现 / 业务表现物理标尺**：掌力可裂青岩，剑气外放三丈，独当一面清剿矿道妖兽。
- **社会 / 财富影响力标尺**：调动执事院配额与十余名淬体境差遣，灵石月入过百。
- **能力 / 感知极限**：尚不能踏空久立，无法抗衡宗门护山阵法。

### 3. Tier 3（骨干层）：灵海境
- **能力表现 / 业务表现物理标尺**：一剑可断小山头，神识覆盖十里，主持护山大阵节点。
- **社会 / 财富影响力标尺**：掌控宗门年例与矿脉分成，与各方代表平起平坐。
- **能力 / 感知极限**：受天道誓约约束，不可亲自向低境者出手。

### 4. Tier 4（巨擘层）：神魄境
- **能力表现 / 业务表现物理标尺**：移山填海，一念之间调动地脉灵气重塑地形。
- **社会 / 财富影响力标尺**：一举动牵动南域宗门格局与灵石市场。
- **能力 / 感知极限**：需以宗门气运供养，宗门衰则修为滞。

### 5. Tier 5（极顶层）：通玄境
- **能力表现 / 业务表现物理标尺**：重塑规则，一剑开辟洞天，剑意可跨越千年不灭。
- **社会 / 财富影响力标尺**：天地剑道秩序的缔造者，一言可为天下法。

## 三、 细分规则与差异化破局法则（System Rules）

1. **标准细分子阶划分**：
   - 每境细分九重，以一重至九重递进；聚气境及以上细分初期/中期/后期/大圆满。

2. **越级破局与非凡表现的逻辑支点**：
   - **常规情况下的阶层壁垒**：跨两个小境界挑战通常极难，高阶者凭借灵气储量与功法品阶形成碾压。
   - **主角能够实现突破/逆袭的核心支点**：林渊依仗眉心剑丸——上古剑祖传承对寻常功法具有天然克制与吞噬之利，辅以黑石矿区矿脉灵压紊乱的地利，方能在聚气境执事面前保命翻盘。

3. **一致性原则**：
   - 严禁境界/职级称号随意混淆漂移；
   - 资产或实力变化必须前后呼应，保持事实自洽。
