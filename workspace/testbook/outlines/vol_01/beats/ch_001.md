# 第 ch_001 章 《灰烬打火机》 编剧细纲

## 🎯 一、 核心戏剧目标与爽点

- **本章核心戏剧目标**：
  沈决在拆迁楼里被裴照堵住，第一次点燃灰烬打火机，烧掉了对方三分钟的记忆。
- **独家看点**：
  反抗的代价先于反抗的快感抵达——他赢了，却在赢的当口掉了一块自己。
- **绝对负向红线（Scene Taboos）**：
  1. 【规则/战力禁忌】：打火机只能烧记忆，不能造成物理伤害，充能上限 3 次。
  2. 【人设/动机禁忌】：裴照不可降智，他是老练的执行者，退场必须有合理动机。
  3. 【叙事/套路禁忌】：不许出现路人突然援手的机械降神。

## 🎬 二、 核心场景脉络

### 场景一（[沈决] 城南拆迁楼·七层 / 堵门）
- 🎯 核心冲突与阻碍：裴照堵住唯一楼梯口，索要灰烬。
- ⚔️ 对抗博弈与对白：沈决用假线索拖延，裴照逐条拆穿。
- 💓 情绪流向与心理台阶：从强撑镇定到手心出汗。
- 🌊 承上启下气口：裴照伸手来抓，沈决按下打火机。

### 场景二（[沈决] 同层·楼道尽头 / 点燃）
- 🎯 矛盾升级与破局代价：火光一闪，裴照的三分钟被烧空。
