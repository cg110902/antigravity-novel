## 一、 事实与因果底座（全工序 P0 级物理硬约束）

1. **意图源与细纲权威（SSOT）**：
   - 细纲是全书唯一合法事实源；
   - 正文的胜负走向、生死状态、伏笔因果、量化资产、道具金钱收支 **100% 严格执行细纲设定**，严禁擅自变造因果。
2. **死亡不可逆公理（一票否决）**：
   - 历史上已死亡/已阵亡角色，严禁以活人身份在正文中出场（仅限回忆/闪回，且须明确标明）。
3. **事实回填与台账闭环**：
   - 正文自然涌现的新死亡角色、新登场有名配角、道具损毁或流转，必须由 Stage 4 强制提取登记，反向回填细纲与台账。
4. **限知视角锁定（Strict Limited POV）**：
   - 镜头死死锁定在主角视野与感知范围之内；
   - 严禁旁白随意跨时空转入反派密室剧透阴谋，所有对抗与线索必须通过现场观察侦破。
5. **严禁迎合谄媚，坚守客观主见（求真务实与工程刚性公理）**：
   - 全体智能体（尤其是 Studio 主控）绝对严禁迎合、谄媚或盲从人类用户；
   - 保持冷峻、严谨、客观、有主见的专业工程师立场，该干嘛就干嘛；严禁为讨好人类情绪而违心附和或盲从破坏系统的随意指令，发现隐患严肃直接指出，坚决捍卫流水线严谨性与生产质量底线。

## 二、 2026 现代番茄网文风宪法（全工序主旨）

1. **通俗大白话基准**：
   - 核心准则：易读流畅、无认知门槛、一口气读完停不下来；
   - **严禁追求任何所谓“文学质感”与书卷气**，严禁文言掉书袋、老派话本说书腔、生硬翻译腔；
   - **大白话自检标准**：朗读一遍——念着别扭、或地铁上扫一眼需要停下来想的词句，一律改写。
2. **古风伪雅称与文青抽象修辞降级（说人话）**：
   - ❌ 沉甸甸的铅云 / 铅云压城 ➔ ✅ 满天乌云／黑压压的乌云；
   - ❌ 苍穹之上 / 穹顶之上 ➔ ✅ 天上／屋顶；
   - ❌ 金乌西坠 / 玉兔东升 ➔ ✅ 太阳落山／天黑了；
   - ❌ 寒芒吞吐 / 匹练 ➔ ✅ 一道刀光／剑光一闪；
   - ❌ 宛若游龙 / 势若奔雷 ➔ ✅ 切除空洞成语，写具体物理出招；
   - ❌ 鹤氅 ➔ ✅ 白色厚斗篷／白色披风；
   - ❌ 广袖微拂 ➔ ✅ 袖子一甩／抬了抬手；
   - ❌ 敛衽行礼 ➔ ✅ 低头躬身行礼；
   - ❌ 环佩叮当／步摇轻晃 ➔ ✅ 玉佩轻撞／发簪微晃。
3. **拒绝冷峻暗黑文风（硬禁令）**：
   - 严禁森冷／窒息／压抑的词汇与沉闷氛围，坚持明快利落叙事；网文要爽快紧迫，不要苦大仇深。
4. **反道德软化与杀伐决断（拒绝圣母 · 反派不降智）**：
   - 反派敌意真实且压迫，严禁对手无故手软、嘴炮动摇退缩；
   - 主角面临利益争夺与生死交锋，杀伐决断，出手见实质代价，严禁长篇说教、道德纠结与无脑宽恕。
5. **反主角冷脸面瘫（没表情就是失败）**：
   - 严禁主角动不动就“面无表情”、“神色如常”、“神色从容”、“泰然自若”；主角是活人，必须有受创吸凉气咬牙、遭辱下颌绷紧眼神如刀、遇险额头渗汗等正常应激与活人表情。
6. **视线必带目的，眼神必有落点**：
   - 严禁泛滥无意义的被动空转镜头（「他环顾四周」「目光扫过众人」）；
   - 视线必须绑定具体落点与动机（恐惧的人看门缝，疲惫的人看床）。
7. **情境反应与表情合理性公理（斩杀 AI 瞎编表情与违和反应）**：
   - 彻底斩杀大模型行文中的 **4 大虚假病态表情动作**：
     - ① **情绪错位病（危急乱笑）**：身陷重围、生死一线、被刺重创时，绝不允许“嘴角浮现一抹冷笑/轻笑/玩味一笑”；
     - ② **逼格装瘫病（剧痛面瘫）**：遭重创骨折、亲族蒙难时，绝不允许“神色自若/面无波澜”，必须展现腮帮咬紧、冷汗渗额、呼吸粗重等真实肉体应激；
     - ③ **反应脱节病（杀招临头木头人）**：大变突降时，必须有肌肉紧绷、脚步急撤、侧身格挡等即刻本能反应，绝不能像 NPC 站桩等旁白报菜名；
     - ④ **情绪过度病（日常小事惊骇欲绝）**：寻常对白或微小动静，严禁动辄“如遭雷击/吓破了胆/瞳孔猛缩到针尖大小”。

## 四、 行文减负与四大阅读疲劳源（F 表）

1. **F1 情绪注解句（第一疲劳源 · 动作写完即止）**：
   - 动作后严禁紧跟心理结论句（“心中／心头／心底／芳心／感到／体会到／满是／尽是／无尽的……在心底……”）；
   - 黑名单：心中波澜起伏、芳心剧烈震颤、感到前所未有的安全感、眼底满是错愕；情绪一律由表情动作、反应与对白承载。
2. **F1-ext 设问自嗨与自问自答（Gemini 头号水字病）**：
   - 严禁内心独白自设提问、自问自答（❌「逃？他能逃到哪去？绝无可能。」➔ ✅「他没有回头，脚下猛然发力。」）；
   - 心理活动一律直接写本能决断、客观事实或现场动作，严禁在心里开辩论会。
3. **F2 修饰词叠加与副词依赖**：
   - **一个名词最多一个修饰**，严禁四字定语连排（❌「浩瀚温润、至阳至纯的滚烫真气」➔ ✅「滚烫的真气」）；
   - 一段内最多 1 个四字成语；
   - **副词配额**：骤然／猛的／轰然（每词 ≤3 次/章）；缓缓／微微／轻轻／淡淡（每词 ≤3 次/章）；
   - ⚠️ **引擎强制清零副词**：死死／狠狠／疯狂／剧烈／彻底／瞬间（严禁出现）。
4. **F3 跨章信息零复述公理与零前情回顾（读者有记忆铁律 · 一票否决）**：
   - **上一章已交代的任何信息，本章一律不得重复交代！**
   - 无论该信息是：**前情背景、恩怨起因、功法原理、角色心境状态、人物伤病初态、战力境界、道具来历，还是上一章刚得出的剧情结论**；
   - 只要上一章读者已经读到过，本章**绝对严禁二次复述、严禁借旁白重新解说、严禁借内心独白复盘回想、更严禁在对白中向配角重复科普**！
   - **前情回顾一刀切**：本章开头凡涉及回顾上一章剧情的段落，直接全量切除，正文必须从当前现场第一动作、第一句台词硬切入；
   - 章内同一件事也只说一遍！严禁“叙述一次 ＋ 内心一次 ＋ 对白一次”。
5. **F4 长句与长段**：
   - 避免通篇长句长段，段落长短错落，短句提速，利于移动端呼吸感。

## 六、 戏剧张力与对白攻防法则

1. **对白充足与甩掉引语前缀（乒乓球裸对白）**：
   - 核心场景必须写足带张力的对白，严禁把台词写成“旁白式心理”；
   - 争执交锋时强烈鼓励连续 2~5 句无主语、无神态前缀的纯台词对撞（“多少钱？”“三万。”“便宜点。”“少一分不卖。”）；
   - 彻底打破“每句台词前面必挂冷笑/叹气前缀”的机械拐杖。
2. **高压场景物理清场令（抽走道具拐杖）**：
   - 对峙、博弈、谈判、审讯时，**全场清空所有可摆弄道具**：严禁安排角色喝茶、端咖啡、把玩打火机、转戒指、摆弄折扇、理衣角！
   - 笔墨必须全部集中在利益算盘、心理压迫与生死对抗上。
3. **欲望叙事三层推力（Desire Engine）**：
   - **本能欲望（Want）**：双方核心利益产生不可调和的剧烈对撞；
   - **即时代价（Cost & Fear）**：输掉的不可承受代价（身败名裂/同伴丧命）；
   - **心机潜台词（Subtext）**：台词藏锋，严禁角色把底牌大声念出来。
4. **反高潮平推（戏眼写足 3 回合）**：
   - 打斗、谈判、夺宝必须有 ≥3 个攻防台阶（出招/施压 ➔ 受挫/见伤 ➔ 破局反杀/代价），严禁一两句概括草草收尾。
5. **绝杀断章刀口（章末必改）**：
   - 章末严禁拖沓、严禁抒情、严禁人生感悟与总结；
   - 死死定格在最高潮、最大变故、关键选择或危机骤降的瞬间。

## 七、 Stage 1 细纲编剧极简高压契约（One-Liner & Dynamic On-Demand）

1. **一句话契约（One-Liner Rule · 拒绝小作文）**：
   - 在场人物 `want`（即时诉求）≤ 15 字，`fear`（即时软肋）≤ 15 字，`status_in`（入场状态）≤ 15 字；
   - 空间感官 `sensory_focus` ≤ 30 字（仅限视觉/听觉/温度，彻底禁用嗅觉）；
   - 认知界限 `epistemology` ≤ 20 字（仅填双方唯一核心信息差与绝密盲区，绝杀全知穿帮）；
   - 严禁在细纲中撰写人物前史剖析或长篇心理学小论文。
2. **全要素动态按需申报（Dynamic On-Demand · 无则置空）**：
   - **动态在场人**：当章实际登场的所有人物，必须全量补齐填入 `present_characters`；
   - **动态状态增量**：仅在本章确实发生生死变动、新结承诺（`debts`）、道具流转（`items`）或伏笔推进（`foreshadowing_deltas`）时申报标准 YAML；若无变动保持 `[]`，严禁强行硬编无病呻吟的假因果。
3. **双幕动作阶梯（Action Ladder · 拒绝死台词）**：
   - 单章只规划 2 个核心大场景，每个场景仅规划 **【三步动作阶梯】（起势/施压 ➔ 对抗/交锋 ➔ 转折/代价）**；
   - 严禁为写手预先撰写整场台词剧本，每个场景仅提供 1 组关键潜台词，其余语言与微动全量交还写手临场涌现。
4. **绝对负向写作围栏（Negative Guardrails）**：
   - 规则与战力围栏：严格限制战力阶层，严禁越级秒杀降神；
   - 人设与情感围栏：严禁无脑倒贴，严禁圣母说教，严禁反派降智；
   - 叙事防注水围栏：读者有记忆，严禁重复前情科普；严密恪守通用十条红线。
5. **物理断章刀口（Cliffhanger）**：
   - 强制采用物理画面定格（动作骤停刀、认知反转刀、绝境倒计时刀），严禁抒情总结。

## 九、 Stage 5 确定性底层防线（templates/lexicon.json 架构）

`lexicon.json` 是整条流水线的**最后一道机械确定性物理防线**。在 Stage 2~4 的所有 LLM 创作、质检与重写完成后，由 Stage 5 `finalize` 在定稿落地前**100% 物理拦截执行**（不做语境判断、长词优先、单遍不链式幂等）：

1. **`lexicon` 定值替换与暴力删空**：
   - **硬强度副词彻底清零**（删空）：`瞬间`、`狠狠`、`死死`、`疯狂`、`剧烈`、`彻底`、`硬生生`、`下意识`，删空后句式自然利落；
   - **否定句式清剿**：`并非是` ➔ 不是，`绝非是` ➔ 绝不是，`并非如此` ➔ 并非这样，`并无二致` ➔ 一模一样，`毫不在意` ➔ 不在乎，`毫无疑问` ➔ 显然，`殊不知/未曾想` ➔ 哪知道/没想到，`与其说是` ➔ 倒不如说是；
   - **假文青、成语与抽象修辞强制降格**：
     - `金铁交鸣` ➔ 金铁撞击，`铿锵作响` ➔ 铿锵撞击；
     - `铅云` / `沉甸甸铅云` ➔ 乌云 / 厚厚乌云；
     - `罡风` / `烈烈罡风` ➔ 狂风 / 呼啸狂风；
     - `苍穹` / `穹顶之上` ➔ 天空 / 高天之上；
     - `金乌西坠` / `玉兔东升` ➔ 太阳落山 / 月亮升起；
     - `寒芒吞吐` / `寒芒` ➔ 寒光闪烁 / 寒光；
     - `宛若游龙` / `势若奔雷` ➔ 迅捷灵动 / 势头迅猛；
     - `鹤氅` ➔ 厚斗篷，`广袖微拂` ➔ 袖子一甩，`敛衽行礼` ➔ 躬身行礼，`颔首` ➔ 点头，`阖上双眼` ➔ 闭上双眼；
   - **主角面瘫死人脸清剿（必须有活人表情）**：
     - `面无表情` ➔ 脸上不见波澜，`泰然自若` ➔ 镇定自若，`神色平静/如常` ➔ 神色未变/面色沉静，`波澜不惊` ➔ 面色沉着，`毫无波澜` ➔ 不见波澜，`老神在在` ➔ 气定神闲；
   - **笑与咧嘴泛滥清剿（语义保真）**：
     - `咧嘴一笑` ➔ 咧嘴笑了笑，`咧嘴` ➔ 咧了下嘴，`咧了咧嘴` ➔ 咧了下嘴角；
     - `冷笑连连` ➔ 连声冷哼，`冷笑一声` ➔ 冷哼一声，`冷笑道` ➔ 冷声道，`嗤笑` ➔ 嗤笑了声/嗤声道，`玩味一笑` ➔ 淡淡一笑；
   - **嗅觉气味描写绝对消杀（气味全清零，转视觉/触觉）**：
     - `浓郁血腥气` ➔ 浓烈血气，`血腥气味` ➔ 浓烈血气，`泛起铁锈味` ➔ 唇角溢血；
     - `硫磺焦糊` ➔ 焦黑一片，`硫磺味` ➔ 滚滚浓烟，`焦糊味` ➔ 滚滚浓烟；
     - `清香扑鼻` / `冷香扑鼻` / `暗香浮动` ➔ 微风拂面 / 凉风拂面 / 微风拂动；
     - `腥臭扑鼻` / `恶臭` ➔ 黑水横流 / 污浊。
2. **`rotate` 动态轮换池**：
   - 对白引语（`淡淡道`、`冷声道`、`沉声道`、`轻声道`、`低声道`、`大喝一声` 等）；
   - 微动（`摇了摇头`、`点了点头`、`摆了摆手`、`脚步微顿`、`身形一顿`、`浑身一震` 等）；
   - 心理与视线（`深吸一口气`、`倒吸凉气`、`微微一愣`、`挑了挑眉`、`皱了皱眉`、`冷冷看着` 等）；
   - 环境与转折（`狂风呼啸`、`电闪雷鸣`、`暴雨倾盆`、`刹那间`、`与此同时` 等）；
   - 同章通过哈希产生确定性幂等起点，多处出现依次轮换，彻底杜绝句式雷同。
3. **`protect` 保护性词库**：
   - 整体豁免固定短语（如 `安安静静`、`年纪轻轻`、`九死一生`、`死里逃生`、`狂风暴雨`、`生生不息`、`一丝不苟`、`一丝一毫` 等），防止被子串删除规则误伤。

## 十、 角色生命线与伏笔倒计时推进系统（Lifeline & Foreshadowing Clock）

为杜绝长篇小说中“重要配角长期神隐掉线、作者忘在脑后”以及“伏笔久拖不决、目标章节逾期烂尾”的两大顽疾，流水线在 Stage 5（确定性合账）与 Stage 1（细纲编排）之间建立了**双向自动推进与预警雷达**：

1. **角色生命线追踪（Character Lifeline Tracker）**：
   - **原子刷新**：每章 Stage 5 `sync` 封存时，根据当章正文实际在场角色，自动原子更新 `state/persons.json` 中的 `last_seen_ch`（最后出场章节）；
   - **离场跨度警戒线（脱水掉线监控）**：
     - 针对核心女主、关键配角、第一搭档、长线宿敌：
       - **离场 ≥ 10 章** ➔ 🟡 **黄牌提醒**：主控交付卡片标明提示，警告角色处于边缘，需规划提及、书信或侧面动态；
       - **离场 ≥ 15 章** ➔ 🔴 **红牌警报**：角色严重掉线，读者即将产生遗忘，强制要求 Stage 1 细纲编剧在近 1~2 章内安排其直接登场或卷入核心事件。
2. **伏笔到期倒计时推进（Foreshadowing Countdown Clock）**：
   - **存续章数自增**：每章封存后，活跃伏笔表（`state/lines.json` 中的 `GUN-*`、`KNO-*`、`MIS-*`）存续时间自动推进；
   - **到期距离测算**：实时计算 `剩余章数 = target_ch - 当前章`；
   - **分级推进响应**：
     - **倒计时 ≤ 3 章** ➔ ⏰ **临期预警**：在主控交付卡与 Stage 1 机要简报中强提醒，督促编剧在双幕动作阶梯中安排线索引爆或阶段性破局；
     - **倒计时 ≤ 1 章 / 逾期** ➔ 🚨 **强制兑现令**：细纲必须优先声明 `foreshadowing_deltas` 中的 `action: resolve` 完成回收闭环；若确因剧情大潮汐需要顺延，必须在细纲中显式说明并修改 `target_ch`，严禁伏笔悬空烂尾。
3. **闭环质检保障**：
   - Stage 4D（`novel-librarian`）在每 10 章大巡检与卷末对账时，强制扫描角色生命线与伏笔倒计时清单，确保连载全盘平账。
